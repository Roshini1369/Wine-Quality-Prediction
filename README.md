# Wine-Quality-Prediction
Wine Quality Prediction
Wine Quality Prediction
This project focuses on predicting the quality of wine based on its chemical characteristics using machine learning classification models. It applies real-world data science techniques to explore how features like acidity, alcohol content, and density influence wine quality.

 Overview
Objective: Predict wine quality scores using supervised learning algorithms.

Dataset: Contains physicochemical attributes of red and white wines (e.g., pH, citric acid, residual sugar).

Target: Wine quality (ordinal score ranging from 0–10).

 Tools & Libraries
Python

Pandas, NumPy – Data manipulation and numerical operations

Matplotlib, Seaborn – Data visualization

Scikit-learn – Model training and evaluation

 Machine Learning Models
Random Forest Classifier

Stochastic Gradient Descent (SGD) Classifier

Support Vector Classifier (SVC)

Key Features
Exploratory Data Analysis (EDA)

Feature importance ranking

Model comparison (Accuracy, Precision, Recall, F1-Score)

Visualizations of data distributions and model performance

 Dataset
Wine Quality Dataset – UCI Machine Learning Repository

 Outcomes
Identification of key chemical factors affecting wine quality

Comparison of multiple classifiers for predictive accuracy

Insightful visualizations to support decision-making in viticulture
